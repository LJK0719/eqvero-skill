# Eqvero Skill 与 MCP

使用自己的 AI 助手查询港美股公司资料、分析投资风险，或提交金融计算任务。MCP 提供工具连接；本仓库的 Skill 提供可选研究方法说明。

## 快速接入

在 [接入页面](https://eqvero.com/developers) 选择客户端，复制对应安装提示词。以 Claude Code 为例：

> 请读取 https://eqvero.com/developers/setup.md?client=claude-code，按照说明为 Claude Code 配置 Eqvero MCP。先检查已有配置并说明修改位置，确认后合并；API Key 在本机安全输入，不要显示在聊天或写入仓库。连接后用 AAPL 做一次只读公司查询，并说明实际结果。

完整、可供助手读取的安装说明：[setup.md](https://eqvero.com/developers/setup.md?client=claude-code)。先检查现有配置并确认修改范围，不覆盖其他服务器或有效凭证。

## 认证

基础版及以上可使用 API/MCP。在 [密钥与用量](https://eqvero.com/developers?tab=keys) 创建专用 Key，按用途选择只读查询或研究与计算。

服务地址：`https://eqvero.com/api/mcp`；传输：Streamable HTTP；请求头：`Authorization: Bearer <EQVERO_API_KEY>`。

Key 只显示一次，保存在客户端安全配置中，不要放进聊天、URL、日志、公开仓库或浏览器应用代码。当前不提供 OAuth 或无 Key 连接。

## 手动配置

以下格式按客户端分别生成，替换占位符后合并进现有配置，不要整份覆盖。含真实 Key 的文件不要提交到仓库。

### Claude Code

在 Claude Code 使用的终端运行命令。

```sh
claude mcp add --transport http eqvero https://eqvero.com/api/mcp --header "Authorization: Bearer <EQVERO_API_KEY>"
```

### Cursor

合并到 Cursor 的 MCP 配置中，不要覆盖已有服务器。

```json
{
  "mcpServers": {
    "eqvero": {
      "url": "https://eqvero.com/api/mcp",
      "headers": {
        "Authorization": "Bearer <EQVERO_API_KEY>"
      }
    }
  }
}
```

### VS Code

合并到 VS Code 的 MCP 配置中；配置根字段为 servers。

```json
{
  "servers": {
    "eqvero": {
      "type": "http",
      "url": "https://eqvero.com/api/mcp",
      "headers": {
        "Authorization": "Bearer <EQVERO_API_KEY>"
      }
    }
  }
}
```

其他客户端须确认支持带请求头的 HTTP MCP；不能把上述格式直接用于只支持 OAuth 或 stdio 的客户端。

## 验证连接

将以下请求发送给已经配置的助手：

> 请使用 Eqvero 的 companies_search 工具查找 AAPL，返回公司名称、股票代码和公司 ID。这里只测试连接，不发起研究或计算。

返回实际公司名称、代码和 ID 才算查询通过。“已复制”或“配置文件已保存”不等于连接成功；需要重载客户端时先重载。验证不创建收费研究任务。

## 可选研究 Skill

MCP 已经可以独立使用。需要研究方法说明时，可读取本仓库 [SKILL.md](SKILL.md)，在确认客户端的 Skill 安装范围后安装；不默认全局安装、不执行下载内容附带的任意脚本。

例如：让助手检查某家公司关联并购的价格与股东风险，解释盈利和现金流的差异，或准备组合风险计算的输入。

## 异步任务

- 查询：`companies_search`、`financials_query`、`evidence_search`、`events_list`、`ownership_list` 等。
- 研究：`research_create` 返回任务 ID，`research_get` 取得进度与报告；原会话追问使用 `research_followup`。
- 计算：`analytics_methods` 查看方法，`analytics_quote` 确认费用，`analytics_create` 提交，`analytics_get` 读取数值结果。
- 响应丢失：保留原 `idempotencyKey`，通过 `research_submission` 查询是否已接受，不使用新 key 重复提交。
- 离开网页或断开 MCP 不取消已接受任务。只有明确停止时使用取消接口；失败重试沿原 taskId，不能循环重跑已交付结果。

API 文档、错误处理与费用说明：[开发者页面](https://eqvero.com/developers?tab=api)。
